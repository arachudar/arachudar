# Arachudar Tamil News Automation Pipeline — Test Infrastructure & Philosophy

## 1. Executive Overview & Test Philosophy

The Arachudar Tamil News Automation Pipeline (`tamil-news-blogger.html`) is a production-grade journalistic aggregation, AI synthesis, and automated publishing system. The pipeline ingests breaking stories from 15 major Tamil news publications, verifies real editorial photographs, synthesizes publication-ready Tamil news articles via NVIDIA NIM LLMs (`nvidia/nemotron-3.5-bolt-e4b`), updates a complex 4,177-line HTML/JS newspaper template, and publishes updates to Google Blogger with social media distribution hooks.

The test framework provides an **opaque-box, multi-tier testing harness** engineered to guarantee system correctness, data integrity, rate-limiting compliance, and publishing reliability under real-world conditions without compromising external services or production assets.

### Core Principles

1. **100% Hermetic Isolation by Default**:
   - Zero outbound TCP socket connections or HTTP requests to external services (`integrate.api.nvidia.com`, `oauth2.googleapis.com`, `googleapis.com/blogger`, or news publication servers) during standard test execution.
   - Any unmocked external network attempt immediately raises `HermeticNetworkViolation`, failing the test fast and preventing quota waste, accidental live publication, or CI flakiness.
   - Live external network testing is strictly quarantined behind the opt-in `--run-live` flag and `live_network` marker.

2. **Absolute Production Template Immutability**:
   - The canonical newspaper layout file (`/Users/davidjulius/Arachudar/tamil-news-blogger.html`) represents the live production UI.
   - Tests **never** mutate the canonical template directly. A global session guard (`guard_canonical_template`) computes the SHA-256 digest at test session initialization and verifies that the digest is bit-for-bit identical upon session teardown.
   - Tests requiring HTML mutation operate exclusively on ephemeral clones generated by `clean_html_template` or lightning-fast structural mocks generated by `minimal_html_template` in `tmp_path`.

3. **Deterministic Virtual Clock Acceleration**:
   - NVIDIA NIM API imposes a hard quota of 40 requests per minute (RPM). The pipeline's `TokenBucketRateLimiter` enforces <= 30 RPM (0.5 req/s) with burst capacity 4.
   - Rather than suffering 2.0s real-time sleep delays during multi-article test runs, the `virtual_clock` fixture simulates elapsed time deterministically in memory, allowing 100+ rate-limited calls to verify pacing in under 50 milliseconds.

4. **Authentic Tamil Unicode Integrity**:
   - Real Tamil news requires valid Unicode representation in the Tamil block (`U+0B80` to `U+0BFF`).
   - The test infrastructure includes a dedicated `unicode_validator` helper that verifies high-density Tamil text, flags English fallback leakage, rejects chain-of-thought reasoning tokens (`<think>...</think>`), and detects double UTF-8 mojibake (e.g. `à®¤à®®à®¿à®´à¯`).

5. **Empirical Fixture Realism**:
   - Fixtures are not synthetic strings or dummy mocks. They are derived from empirical surveys of the 15 Tamil sources, authentic OpenAI/NIM completion JSON envelopes, and Google Blogger API v3 specifications.

## 4. 4-Tier Test Coverage Methodology

The test suite organizes test cases into four distinct layers according to the opaque-box test engineering standard:

```
┌────────────────────────────────────────────────────────┐
│  Tier 4: Real-World Scenarios (>= 7 tests)             │
│  Full end-to-end pipelines, dry-runs, CI workflows     │
├────────────────────────────────────────────────────────┤
│  Tier 3: Pairwise Integration Tests (>= 14 tests)       │
│  Cross-component contracts & data flow transitions     │
├────────────────────────────────────────────────────────┤
│  Tier 2: Boundary, Negative & Fault Injection (>= 70)  │
│  Quota exhaustion, HTTP 429/503, malformed data, WAF   │
├────────────────────────────────────────────────────────┤
│  Tier 1: Feature Isolation Unit Tests (>= 70 tests)    │
│  Independent verification of F1 through F14            │
└────────────────────────────────────────────────────────┘
```

### Tier 1: Feature Isolation Unit Tests (`tests/test_tier1_features.py`)
- **Objective**: Verify each feature (F1 through F14) independently in pure isolation under normal operating conditions.
- **Scope**: At least 5 distinct test cases per feature (14 features × 5 = >= 70 tests).
- **Target Areas**:
  - Feed parsing accuracy across all 15 sources.
  - Image URL extraction, protocol parsing, and high-resolution URL rewriting.
  - Negative filter blocklisting (logos, favicons, banners, 1x1 pixels).
  - Deduplication cache insertion, query, and persistence.
  - Token bucket rate limiter token replenishment and burst consumption.
  - Tamil synthesizer prompt formatting and JSON output parsing.
  - HTML populator slot injection and script tag modification.
  - Blogger client OAuth2 payload formatting and post request building.
  - Social media text truncator (280-char limit for X).
  - GitHub Actions workflow YAML parsing and structure validation.
  - Dry-run CLI argument parsing and exit codes.

### Tier 2: Boundary, Negative & Fault Injection Tests (`tests/test_tier2_boundaries.py`)
- **Objective**: Push the system against edge cases, boundary conditions, malformed inputs, and upstream failures.
- **Scope**: At least 5 distinct boundary/negative test cases per feature (14 features × 5 = >= 70 tests).
- **Target Areas**:
  - Empty feeds, 404 feed endpoints, XML parse errors, truncated payloads.
  - Missing image tags, relative image URLs, corrupt image byte headers.
  - Extreme cache sizes, concurrent cache writes, corrupt `seen_articles.json`.
  - Burst depletion, HTTP 429 Too Many Requests, HTTP 503 Overload, unmapped models.
  - Markdown-wrapped JSON (````json ... ````), truncated JSON, `<think>` token leakage.
  - Non-Tamil text generation, mojibake strings, zero-length summaries.
  - Corrupt HTML template anchors, missing DOM IDs, mismatched static card count.
  - Expired OAuth2 refresh tokens (`invalid_grant`), Blogger permission denied (403).
  - Social hook API timeouts, oversized text payloads.
  - Missing GitHub secrets environment variables.

### Tier 3: Pairwise Cross-Feature Integration Tests (`tests/test_tier3_pairwise.py`)
- **Objective**: Verify the data flow and interface contracts between interacting modules.
- **Scope**: At least 14 pairwise combinations across pipeline boundaries.
- **Key Pairs**:
  - F1 (Feed Ingestion) ↔ F3 (Image Extraction): Extracted feed items retain correct image URLs.
  - F3 (Image Extraction) ↔ F4 (CDN Enhancement): Extracted images are correctly upgraded to 1200px.
  - F4 (CDN Enhancement) ↔ F5 (Negative Filter): Enhanced URLs are checked against negative rules.
  - F1 (Feed Ingestion) ↔ F6 (Deduplication): Only new articles pass to the next stage.
  - F6 (Deduplication) ↔ F7 (Rate Limiter): Deduplication minimizes calls through the rate limiter.
  - F7 (Rate Limiter) ↔ F8 (Tamil Synthesis): LLM queries are safely spaced under 30 RPM.
  - F8 (Tamil Synthesis) ↔ F9 (HTML Populator): ProcessedArticle fields correctly populate DOM slots.
  - F8 (Tamil Synthesis) ↔ F10 (Blogger Publishing): Synthesized Tamil text formats Blogger HTML.
  - F9 (HTML Populator) ↔ F10 (Blogger Publishing): Article IDs in static HTML match Blogger references.
  - F10 (Blogger Publishing) ↔ F11 (Social Hooks): Published post URL and title feed social stubs.
  - F12 (CI/CD) ↔ F13 (Dry-Run): Workflow invokes dry-run verification with correct flags.

### Tier 4: Real-World Scenarios & Workload Verification (`tests/test_tier4_scenarios.py`)
- **Objective**: Execute end-to-end simulated production runs across multiple categories and sources.
- **Scope**: At least 7 end-to-end workflow scenarios.
- **Key Scenarios**:
  - Standard Morning News Run (ingesting 15 sources, generating 25 articles, updating HTML, mock publishing).
  - Flash News Breaking Story Run (high-priority article tagged `isFlash: true` inserted into ticker and lead slot).
  - Source Outage & Fallback Scenario (several news endpoints return 500/404, pipeline gracefully continues with remaining sources).
  - AI Quota Throttling Scenario (NVIDIA returns 429, rate limiter triggers backoff, job succeeds without data loss).
  - E-Paper Generation Scenario (4-page broadsheet populated with 15 required fields per page).
  - Dry-Run Execution Scenario (complete pipeline executed with `--dry-run`, ensuring zero live writes).
  - Template Invariance Scenario (verifying that after a complete pipeline execution, canonical template is untouched and isolated clone is valid).

## 5. Mocking & Interception Engine

The test harness uses a unified hermetic interceptor implemented in `tests/conftest.py` and `tests/helpers/network_guard.py`:

```
               Outgoing HTTP / Socket Call
                          │
                          ▼
            [ hermetic_network_guard ]
                          │
         ┌────────────────┴────────────────┐
         ▼                                 ▼
   --run-live active?               Default (Hermetic)
         │                                 │
     Pass-through                          ▼
    to live network           Inspect Method, URL & Headers
                                           │
         ┌───────────────┬─────────────────┼────────────────┬──────────────┐
         ▼               ▼                 ▼                ▼              ▼
   Image URL?      NVIDIA NIM?       Blogger API?     OAuth2 Token?   Feed XML?
         │               │                 │                │              │
      Return          Return            Return           Return         Return
   DUMMY_JPEG       Tamil Chat         Blogger          Bearer         Master
     Bytes          Completion       Post Resource       Token        Feed XML
         │               │                 │                │              │
         └───────────────┴─────────────────┼────────────────┴──────────────┘
                                           │
                                  No handler matched?
                                           │
                                           ▼
                            Raise HermeticNetworkViolation!
```

### Interception Rules
1. **Image CDNs & Extensions**: Matches `.jpg`, `.jpeg`, `.png`, `.webp`, `?w=1200`, `=s0-w1200`. Checks against negative keywords (`logo`, `icon`, `placeholder`). If negative, returns HTTP 404; otherwise returns `200 OK` with `DUMMY_JPEG_BYTES`.
2. **NVIDIA NIM API**: Matches `integrate.api.nvidia.com`. Returns OpenAI-compatible chat completion payload with authentic Tamil article content conforming to the Arachudar schema.
3. **Google OAuth2**: Matches `oauth2.googleapis.com/token`. Returns valid Bearer access token payload with 3600s TTL.
4. **Google Blogger v3**: Matches `googleapis.com/blogger/v3/blogs/.../posts`. Returns valid `blogger#post` resource with live status and Tamil labels.
5. **News Feeds**: Matches domains of the 15 Tamil publications. Returns authentic Media-RSS / Atom / Sitemap XML.

## 7. How to Execute Tests

### 1. Execute Smoke Test (Test Infrastructure Verification)
```bash
python3 -m pytest -v tests/test_infra_smoke.py
```

### 2. Execute Full Hermetic Test Suite (All Tiers)
```bash
python3 -m pytest -v tests/
```

### 3. Execute Individual Test Tiers
```bash
# Tier 1: Feature Isolation Unit Tests
python3 -m pytest -v tests/test_tier1_features.py -m tier1

# Tier 2: Boundary, Negative & Fault Injection Tests
python3 -m pytest -v tests/test_tier2_boundaries.py -m tier2

# Tier 3: Pairwise Cross-Feature Integration Tests
python3 -m pytest -v tests/test_tier3_pairwise.py -m tier3

# Tier 4: Real-World Workload Scenarios
python3 -m pytest -v tests/test_tier4_scenarios.py -m tier4
```

### 4. Execute Optional Live Network Smoke Tests
```bash
python3 -m pytest -v tests/ --run-live -m live_network
```
